# sun-pet
平静 祥和 令人向往 谁不想把电脑桌面变成太平间
一个 Windows 桌面宠物：透明无边框、始终置顶，默认以 100 px/s 在桌面工作区内随机漫步。
双击 `启动桌宠.bat`，或直接双击 `孙笑川桌宠.exe`。
首次启动时如有 SmartScreen 提示，选择“仍要运行”。退出请右键桌宠，点击控制台右下角的 退出。
左键单击桌宠	立即停住 2 秒，变为尸体形态。可重复触发。
右键单击桌宠	打开/收起“桌宠控制器 - 记忆碎片”复古控制台。
控制台“音频 / AUDIO”	勾选/取消“循环播放”来开启或关闭循环音频。
控制台“移动速度 / SPEED”	在 30–300 px/s 之间调节移动速度。
控制台“桌宠大小 / SIZE”	在 160–480 px 之间实时调节桌宠大小，窗口和图片同步缩放。
控制台“退出”	关闭桌宠并退出程序。
音频在程序启动时自动循环播放 `仙乐.mp3`；关闭后再开启会从暂停处继续。
